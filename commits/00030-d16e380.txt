1e §4: fix Decoy/Ambush's missing low-health + dodge/Riposte follow-ups
Decoy and Ambush's own original code (useDecoyLegacy/useAmbushLegacy)
never called lowHealthTriggerChecks at all; Ambush's original also never
called applyDodgeBlockNegateBonuses/maybeRiposte/the evasion-bonus trio.
Every other player action (playerAttack/useDisarm/useElementAbility)
calls all of these. Both gaps were already disclosed in pipeline.js's
own comments from the 1e-ii/1e-iii work; this closes them.

Decoy gets just the missing lowHealthTriggerChecks call, placed in the
same position every other action uses it, leaving Decoy's own existing
unconditional dodge/Riposte follow-up call untouched.

Ambush gets the full block, but in Decoy's UNCONDITIONAL form, not
playerAttack/useDisarm's gated "retaliation.damage === 0" form: Ambush
(like Decoy) excludes its own target from this round's remaining
initiative via resolveRemainingInitiativeActions' excludeIndex, which is
always the same enemy that function captures as its own
callerActiveIndex at entry -- so that enemy's damage is the ONLY damage
the function would ever attribute to retaliation.damage, and it's
excluded. retaliation.damage is therefore always null, never 0, making
the gated form silent dead code for an excludeIndex-shaped action --
confirmed by the new P1E-II-A-DODGEBLOCK-FIX-01 test actually failing
against the gated form before this was caught and switched to Decoy's
shape.

Verified: both gaps added new, non-parity tests (P1E-II-D-LOWHEALTH-FIX-01,
P1E-II-A-LOWHEALTH-FIX-01, P1E-II-A-DODGEBLOCK-FIX-01) that directly
confirm the new behavior fires on the new code and is confirmed absent on
the untouched Legacy oracle -- not a checkParity comparison, since the
whole point is that these two now differ from Legacy on purpose. A
deliberate sanity-break (reverting each call) was caught by each new
test. Layer 2 (boss_sweep/plus3_run) shows the expected small, real
balance shift at two cells that actually exercise these effects
(dregnar/warrior/normal, arbitarius/warrior/normal): win rate and
down-frequency move a few points, nothing near a double-digit swing.
