Add codex snapshot workflow for the nightly Codex Tracker
On each push to the default branch, GitHub Actions runs tools/codex/build.sh:
it snapshots the js/data registries, diffs them against the previous build,
renders the item and enemy codex text, runs tools/audit.js, and commits the
output to the codex-data branch. The game itself never loads these files.
