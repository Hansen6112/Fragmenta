Completes the full 14-member "Avatar of X" cluster. All four triggers
generalize to (holder, holderRole), but investigation showed most of
each effect's real mechanic has NO ally analog at all to widen
alongside the trigger:

- Avatar of Fate: critMultiplier is scoped entirely to state.combat
  (bails via `if (!combat) return 1`) -- there is no ally crit system
  to double in the first place. Its cheatDeath save is the same:
  cheatDeath is only ever dispatched for the player

  plug avatarOfFateSaveUsed into either. Both stay player-only.

  reasoning as Freedom/Creation's cooldown halves. Only the Magic buff
  (now via grantTemporaryStatBuff, inert for an ally like Creation's)
  and the Knowledge buff (written to the host for parity, also inert --
  Expanding Mind reads combat.player.knowledgeBuffAmount directly)
  generalize.

  "player" (combat.cooldowns has no ally analog). The window's +25%

  widens via modifierStateHost -- a real, working ally-side effect. The
  frozen-buff-duration read and new-cooldowns-cost-0 read stay
  player-only; an ally's own buffs are NOT frozen by this window, a
  deliberate simplification rather than a new cross-mechanic build-out.

  was already a registry entry (always:avatar_of_passing_lifesteal,

  War's identical always:avatar_of_war_lifesteal entry, which slice 5
  left untouched. Both fixed here.
